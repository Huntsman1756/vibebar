# Security Policy

VibeBar is a local-first application. Supported versions are the current main branch and the latest released version until a newer release supersedes them.

If you discover a security issue, report it privately through the repository security advisory workflow or the maintainers' private vulnerability-reporting channel for this release. Do not open a public issue for sensitive reports unless the maintainers have asked you to do so.

When reporting a vulnerability, please do not attach logs, cookies, tokens, prompts, responses, source code, database files, or generated bundles. Share only the minimum reproduction steps and the smallest safe evidence needed to understand the issue.

Please keep any proof-of-concept data sanitized and local. Avoid real account data, personal repository identifiers, and any credentials in screenshots, recordings, or text.
